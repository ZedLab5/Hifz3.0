# Open Quran Dataset Attribution & License

This application bundles complete, verified text datasets of the Holy Qur'an comprising all 114 Surahs and 6,236 Ayahs.

## Data Sources & Editions

1. **Arabic Text (Uthmani Script)**
   - **Edition**: Quran Uthmani (`quran-uthmani`)
   - **Source**: King Fahd Glorious Quran Printing Complex (Madinah) & Tanzil.net project
   - **License**: Creative Commons Attribution 3.0 Unported / Open Quran Text License

2. **English Translation**
   - **Edition**: Saheeh International (`en.sahih`)
   - **Translators**: Emily Assami, Mary Kennedy, Amatullah Bantley
   - **Source**: Dar Abul-Qasim / Al-Quran Cloud Open Data
   - **Usage**: Free for non-commercial distribution and spiritual learning

3. **English Transliteration**
   - **Edition**: Phonetic English Transliteration (`en.transliteration`)
   - **Source**: Tanzil.net & Al-Quran Cloud Open Dataset
   - **Usage**: Standard phonetic romanization according to tajweed rules

## Canonical Integrity
- Total Surahs: 114
- Total Verses (Ayahs): 6,236
- Verse counts verified against canonical Hafs an Asim reading standard.
